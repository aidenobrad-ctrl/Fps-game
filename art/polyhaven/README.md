# Poly Haven height maps (CC0)

Height (displacement) maps from [Poly Haven](https://polyhaven.com), released under CC0,
downsized to 512 x 512 (16-bit). `art/blender/textures.py` lays them over the soldier's
clothes and kit, at their real size, when it bakes the normal maps:

| File | Poly Haven asset | Real size | Used for |
| --- | --- | --- | --- |
| `stretch_poplin_disp_512.png` | Stretch Poplin | 291 x 281 mm | the uniform's cloth, under a ripstop grid |
| `hessian_230_disp_512.png` | Hessian 230 | 269 x 267 mm | the plate carrier and pouches (shrunk, as a nylon weave) |
| `denim_fabric_03_disp_512.png` | Denim Fabric 03 | 271 x 271 mm | webbing, straps, belt and laces (twill) |
| `brown_leather_disp_512.png` | Brown Leather | 400 x 400 mm | the boots |
| `scuba_suede_disp_512.png` | Scuba Suede | 285 x 279 mm | the gloves |
